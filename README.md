# Moriarty Photography

Public catalog published to Netlify. Stills and admin live on GitHub Pages only.

- Every still is 1920×1080.
- Stills never deploy to Netlify.
- Helvetica, slick, gold accent only.
- Logo in the black.

## Structure
- `public/` — Netlify publish directory (no stills).
- `stills/` — 1920×1080 images served via GitHub Pages.
- `admin/` — door that links to the stills tool on GitHub Pages.

Enable GitHub Pages on the `main` branch for stills access.
Configure Netlify to publish the `public` directory.
